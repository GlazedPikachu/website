Frequently Asked Questions

    

      
What is Meowdoku?

      
Meowdoku is a grid-based logic puzzle where players must place cats onto specified colored regions according to specific placement rules (similar to Star Battle or Sudoku logic).

    

    

      
How does this solver calculate the answer?

      
The solver uses computer vision algorithms in JavaScript to extract the puzzle grid colors, followed by logical propagation and constraint satisfaction algorithms to compute valid cat placements.
